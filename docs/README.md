## 📚 Documentation Categories

### Guides (`guides/`)
Setup instructions, build troubleshooting, and rebuild guides.

### Features (`features/`)
Feature-specific documentation including shopping sessions model and implementation.

### Backend Docs (`backend-docs/`)
Backend implementation guides for authentication, expenses, groups, models, and schemas.

### Testing (`testing/`)
Testing guides, verification checklists, and testing summaries.

### Security (`security/`)
Security overview, patches, hardening notes, and token refresh fixes.

### Development (`development/`)
Session summaries, fix summaries, and development notes.

### Architecture (`architecture/`)
Database schema, architecture decision records, and design documents.
