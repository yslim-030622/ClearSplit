# ClearSplit Docs

This folder contains the current documentation for repository structure, component behavior, dependencies, and operations.

## Start Here

- `INDEX.md`: complete documentation index.
- `project-overview.md`: product and architecture overview.
- `repository-map.md`: full section-by-section tree with responsibilities.
- `file-tree-full.md`: source-oriented full file tree snapshot.
- `dependencies.md`: backend, iOS, and infrastructure dependency map.
- `backend-reference.md`: backend API, services, models, and migrations.
- `ios-reference.md`: iOS architecture, networking, viewmodels, and screens.
- `workflows-and-operations.md`: local setup, CI/CD, scripts, and deployment flow.

## Scope

These docs are written from source code in:

- `backend/`
- `ios/`
- `.github/workflows/`
- `scripts/`
- root configuration files

## Legacy Docs

Older topic files under folders such as `backend-docs/`, `features/`, `guides/`, and `security/` are kept for historical context, but the files listed above are the authoritative starting point.
